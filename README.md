# 宝宝成长助手 V1

一个为家庭自用设计的本地优先 PWA，用于安排宝宝作息、辅食与日常成长记录。数据默认只保存在当前浏览器的 IndexedDB 中，不上传服务器。

## V1 功能

- 今日首页：当前事项、完成后自动推进、下一事项、睡眠汇总、成长时间线
- 可配置作息模板：起床、喝奶、辅食、午睡等间隔可调整
- 日常记录：奶、水、便便、睡眠、身高、体重、出牙和新食物观察
- 辅食计划：600 道分阶段食谱、7 天菜单、替换、收藏、忌口/不喜欢和购物清单
- 多宝宝、本地备份导入、离线使用和可安装 PWA
- 提醒：应用打开时会核对逾期事项；在浏览器允许且系统未限制时尽力发送通知

## 本地运行（Windows PowerShell）

本项目没有第三方运行依赖。请不要直接双击 `index.html`，应通过本地 HTTP 服务打开：

```powershell
cd F:\codex\baby-meal-pwa
npx serve .
```

如果不想使用 `npx`，也可使用电脑已有的 Python：

```powershell
cd F:\codex\baby-meal-pwa
python -m http.server 4173
```

然后访问 `http://localhost:4173`。首次打开时填写宝宝信息；安装到桌面/手机后可获得更接近原生应用的体验。

## 测试

```powershell
npm.cmd test
```

PowerShell 若阻止 `npm.ps1`，请使用上面的 `npm.cmd`，不需要修改系统执行策略。

## 数据与提醒说明

- 清理浏览器站点数据、无备份地更换浏览器或设备会丢失记录；请定期在“设置 → 数据管理”导出 JSON 备份。
- 通知需要用户授权。PWA/网页关闭或进入后台后，能否准时通知取决于浏览器、操作系统、省电策略和是否允许后台运行。
- 本地静态 PWA 无推送服务器，因此不能承诺应用完全关闭后仍像系统闹钟一样可靠。重要事项仍建议同时使用手机系统闹钟。

## 部署到 GitHub Pages

仓库推送后，可在 GitHub 仓库的 `Settings → Pages` 中选择 `Deploy from a branch`，分支选择 `main`、目录选择 `/ (root)`。部署完成后 GitHub 会显示访问地址。
