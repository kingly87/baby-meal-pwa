# 深色模式生活趋势标签可读性设计

## Objective

修复“成长 → 生活趋势”在系统深色模式下未选中指标和时间范围按钮文字几乎不可见的问题，同时保持现有选中状态、布局和交互不变。

## Current State and Root Cause

- 深色主题将 `--ink` 设置为浅色 `#fff2e7`，用于正文和控件文字。
- 生活趋势未选中按钮将背景硬编码为浅色 `#fff7f0`，因此深色模式出现浅底浅字。
- 选中按钮使用橙色 `var(--accent)` 背景和白色文字，所以选中后才恢复可读。
- 菜单页同类切换按钮已经使用 `var(--surface)` 作为未选中背景，在明暗主题中均可读。

## Design

将 `.trend-metrics button` 和 `.trend-ranges button` 的未选中背景从固定浅色改为 `var(--surface)`。选中状态继续使用现有橙色背景与白色文字，不改变 HTML、JavaScript、数据结构、按钮尺寸或交互。

采用现有主题变量而不是新增深色专用覆盖或新颜色令牌，以复用项目已经验证的菜单切换按钮模式，并避免明暗主题规则分叉。

## Files

- `assets/styles/app.css`：修改生活趋势未选中按钮背景。
- `tests/daily-trends-ui.test.js`：增加样式契约回归断言，确保趋势按钮使用主题表面色且选中状态仍使用强调色。
- `service-worker.js`、相关 PWA 测试：缓存修订从 `r31` 升为 `r32`，让已安装 PWA 获取新样式。
- `PROJECT_STATE.md`：记录已验证的修复事实。

## Verification

1. 先增加回归测试，并确认测试因固定浅色背景而失败。
2. 最小修改 CSS 后确认目标测试通过。
3. 运行 `npm.cmd run check`、完整 `npm.cmd test` 和 `git diff --check`。
4. 在手机宽度的深色模式中检查睡眠、奶量、便便、尿尿以及 7/14/30 天按钮：未选中标签可读，选中标签可读，布局无横向溢出。
