# V1 验收清单

## 首次使用

- [ ] 打开后显示宝宝建档页，填写姓名、生日和辅食阶段后进入首页
- [ ] 首页显示当前事项、下一事项、今日睡眠和成长时间线
- [ ] 点击“完成”后，当前事项推进到下一项

## 记录与计划

- [ ] 快速记录奶量、水量、便便和睡眠后，时间线立即更新
- [ ] 生成本周菜单后显示 7 天、每天 2 餐，共 14 餐
- [ ] 忌口食材不会出现在自动菜单，菜品可替换、收藏并生成购物清单
- [ ] 新食物可建立连续 3 天观察记录
- [ ] 身高、体重和出牙记录可保存；至少两个有效测量点时显示趋势曲线

## 设置与数据

- [ ] 修改作息模板后，未完成事项按新模板生成/推进
- [ ] 可添加、切换和删除宝宝（至少保留一个）
- [ ] 可导出 JSON 备份；导入有效备份后数据恢复
- [ ] 浏览器允许通知时能启用提醒；拒绝或不支持时显示明确状态

## PWA 与离线

- [ ] 通过 HTTPS 或 localhost 打开后可安装
- [ ] 首次完整加载后断网刷新，应用外壳仍可打开
- [ ] 清理浏览器站点数据前，界面会提示先导出备份
